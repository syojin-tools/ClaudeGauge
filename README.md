# Claudeゲージ for Windows

Claude の 5時間セッションの使用率と、リセットまでの残り時間を、Windows のタスクバーに常時表示する常駐アプリです。

> 本ソフトは Anthropic 社とは関係のない非公式ツールです。Claude は Anthropic 社の商標です。

**ダウンロード（ビルド済み・無料）→ https://syojin.com/tools/claude-gauge**

このリポジトリはソースコードの公開用です。何を読んで何をしているかを確認できるように置いています。
配布物と同じものを、`build.cmd` をダブルクリックするだけで手元でビルドできます（Visual Studio も .NET SDK も NuGet も不要）。

主な特徴:

- Claude デスクトップアプリがローカルに記録している使用量ファイルを **読むだけ**。認証情報（トークン・Cookie・パスワード）には一切触れません
- **外部への通信を一切行いません**
- Claude 側のフォルダには **書き込みません**（共有読み取りで開くため、本家アプリの動作も妨げません）
- Windows 同梱の C# コンパイラだけでビルドできる単一 EXE（約 55KB）

## 1. 起動方法

`dist` フォルダの中の **ClaudeGauge.exe** をダブルクリックするだけです。
インストール作業はありません。数秒でタスクトレイ（画面右下の時計の左側）に数字のアイコンが出ます。

### ⚠ 最初の1回だけ：アイコンを常に表示させる

Windows 11 は、新しいアプリのトレイアイコンを **最初は隠します**。
時計の左にある **「∧」（山形のマーク）** をクリックすると、隠れているアイコンが出てきます。
その中の数字のアイコンを、**マウスでドラッグして時計の近くに引っ張り出す**と、以後は常に表示されるようになります。

### 自動起動

アプリの詳細ウィンドウを開き、**「Windows 起動時に自動で起動する」** にチェックを入れてください。
それだけで完了です。スタートアップフォルダを開いたりする必要はありません。

## 1-2. 別のパソコンに入れる

`ClaudeGauge.zip`（29 KB）を、USBメモリやクラウドストレージでコピーするだけです。インストーラーはありません。

1. zip を相手のPCにコピーして、右クリック →「**すべて展開**」
2. 出てきた `ClaudeGauge.exe` を、消えない場所に置く（例：ドキュメントの中に `ClaudeGauge` フォルダを作る）
3. ダブルクリックで起動
4. 詳細ウィンドウを開いて「Windows 起動時に自動で起動する」にチェック

### 動作条件

- **Windows 10 / 11（64ビット）** — 特別なインストールは不要です
- **そのPCに Claude デスクトップアプリが入っていて、ログイン済みであること**
  使用量データはそのPCの Claude アプリが記録したものを読むので、Claude が入っていないPCでは数字が出ません

### 「WindowsによってPCが保護されました」と出たら

インターネットやUSB経由でコピーした exe には、Windows が警告を出します（このアプリが危険という意味ではなく、開発元の署名がないためです）。

- **「詳細情報」→「実行」** を押せば起動します
- 毎回出るのが煩わしい場合は、exe を右クリック →「プロパティ」→ 下のほうの「**ブロックの解除**」にチェック → OK

### 設定は引き継がれません

設定（更新間隔・閾値・表示位置）はPCごとに保存されるため、新しいPCでは既定値から始まります。設定し直してください。

## 2. 使い方

| 操作 | 結果 |
|---|---|
| アイコンにマウスを乗せる | セッション使用率・週次使用率・リセットまでの時間が出ます |
| アイコンを左クリック | 詳細ウィンドウが開きます |
| アイコンを右クリック | メニュー（詳細を開く／今すぐ更新／終了） |

### タスクバー上の大きい表示

トレイアイコンは Windows の仕様で **16×16 ピクセル固定** のため、数字が小さくて読みにくくなります。
そこで、タスクバーの上に重ねて大きな文字で表示するパネルを標準で出しています。

```
( ◔ ) 18%  残り 3:33
```

- 左のリングが 5時間セッションの使用率、数字が同じ値の % 表示
- 右は **5時間セッションがリセットされるまでの残り時間**（時:分）
- 週次はここには出しません。詳細ウィンドウで確認できます

- **ドラッグで好きな位置に動かせます**（位置は記憶します）
- **クリックすると詳細ウィンドウが開きます**
- **右クリックでメニュー**（詳細を開く／今すぐ更新／終了）
- 位置がおかしくなったら、詳細ウィンドウの「位置を戻す」で既定位置に戻ります
- 不要なら詳細ウィンドウの「タスクバーの上に数字を大きく表示する」のチェックを外してください

### トレイアイコンの見方

- 数字は **5時間セッションの使用率（%）** です
- 数字の色
  - 通常色 … 60% 未満
  - オレンジ … 60% 以上
  - 赤 … 80% 以上（設定で変更できます）
- **数字の下に赤い横線が付いているとき**は、5時間セッションではなく **週次の使用率** を表示しています
  （週次が 80% を超えると自動で切り替わります。この閾値も設定で変更できます）
- **`!` が出ているとき**は数字を取得できていません。マウスを乗せるか詳細ウィンドウを開くと理由が出ます

### 詳細ウィンドウでできること

- 5時間セッションと週次の使用率、リセットまでの残り時間
- 過去 30 日の推移グラフ
- 更新間隔／通知する使用率／週次に切り替える使用率の変更
- 通知の ON / OFF
- Windows 起動時の自動起動の ON / OFF
- 診断ログの保存（うまく動かないときに使います）

ウィンドウの「閉じる」や「×」を押しても常駐は解除されません。完全に終了するときは、トレイアイコンを右クリックして「終了」を選んでください。

## 3. 動かないときの確認手順

### 数字が出ない・`!` が出ている

1. **Claude デスクトップアプリを起動してログインしているか確認してください。**
   このアプリは、Claude デスクトップアプリが記録している使用量データを読んで表示しています。
   Claude デスクトップアプリが動いていないと、数字は更新されません。
2. Claude デスクトップアプリを起動したまま、**5〜10 分ほど待ってください。**
   Claude 側がデータを書き込むのが約 5 分間隔のため、起動直後は少し時間がかかります。
3. トレイアイコンを右クリックして「今すぐ更新」を押してください。

### 「Claude デスクトップアプリが起動していないため、数字が止まっています」と出る

Claude デスクトップアプリを起動すれば、数分以内に最新の数字に戻ります。
このメッセージには **最終更新が何分前か** も出ますので、どのくらい古い数字かが分かります。

### それでも直らない

詳細ウィンドウの **「診断ログを保存」** を押して、デスクトップにファイルを保存してください。
そのファイルを渡していただければ原因を調べられます。
（診断ログにパスワードや認証情報は一切含まれません。このアプリは認証情報を読みません）

### アイコンが見当たらない

時計の左の **「∧」** をクリックして、隠れているアイコンの中を確認してください（上記「最初の1回だけ」を参照）。

## 4. アンインストール手順

1. トレイアイコンを右クリックして **「終了」**
2. 詳細ウィンドウを開いていた場合は、先に「Windows 起動時に自動で起動する」の **チェックを外して**ください
   （外し忘れた場合は、下の「取り消しを忘れた場合」を参照）
3. `ClaudeGauge` フォルダごと削除
4. 設定ファイルも消す場合は、エクスプローラーのアドレス欄に `%APPDATA%\ClaudeGauge` と入力して開き、そのフォルダを削除

### 取り消しを忘れた場合

アプリを削除する前にチェックを外し忘れると、起動時に「見つかりません」というエラーが出ることがあります。
その場合はアプリを一度元の場所に戻してチェックを外すか、Windows の「設定 → アプリ → スタートアップ」で
**ClaudeGauge** を OFF にしてください。

## 5. 仕組みと注意点

- このアプリは、Claude デスクトップアプリが `%APPDATA%\Claude\plan-usage-history.json` に記録している使用量を **読むだけ** です
- **Claude 側のフォルダには一切書き込みません。** 読み取りも共有モードで行うため、Claude デスクトップアプリの動作を妨げません
- 認証情報（トークン・Cookie・パスワード）には **一切触れません**
- 表示される数字は claude.ai の「設定 → 使用量」と同じ値です（更新のタイミング差だけずれます）
- リセット時刻は履歴からの **推定値**（誤差 ±5 分程度）です。画面には「推定」と明記しています
- 週次のリセット時刻は、履歴の中にリセットの記録が現れるまで「不明」と表示されます
- 公式に用意された機能ではないため、**Claude デスクトップアプリ側の変更で動かなくなる可能性があります**。
  その場合はトレイに `!` が出ます（黙って古い数字を出し続けることはありません）

## 6. 開発者向け

### ビルド

`build.cmd` をダブルクリックすると `dist\ClaudeGauge.exe` が作られます。
Windows に最初から入っている C# コンパイラ（.NET Framework 4.8）だけを使うため、
Visual Studio も .NET SDK も NuGet も不要です。

### ファイル構成

| ファイル | 役割 |
|---|---|
| `src/Constants.cs` | 参照先パス・JSON のキー名・既定値。**Claude 側の仕様変更時はここだけ直せばよい** |
| `src/UsageReader.cs` | 履歴ファイルの読み取りとリセット時刻の推定 |
| `src/Theme.cs` | ライト／ダークテーマ判定と配色 |
| `src/TrayIconRenderer.cs` | トレイアイコンの描画、表示内容の判定 |
| `src/TrendChart.cs` | 30 日推移の折れ線グラフ |
| `src/SummaryPanel.cs` | 詳細ウィンドウ上部の数値表示 |
| `src/DetailForm.cs` | 詳細ウィンドウと設定 UI |
| `src/Settings.cs` | 設定の保存とスタートアップ登録 |
| `src/DiagLog.cs` | 診断ログ |
| `src/Program.cs` | 常駐処理・ファイル監視・通知 |
